Healthcare Data Reliability & Early Anomaly Detection Engine

Stack: Snowflake, Mage AI, Azure DevOps, DataOps Studio UI

Acted as Data Reliability Engineer managing production healthcare streams. Discovered that low-quality data was propagating downstream and disrupting Clinical Operations (Clin-Ops) teams.

Complex Labor Shift Validation & Lifecycle Auditing Engine

Stack: Python, SQL, Automated Quarantine Workflows

Engineered custom business logic validation for labor shift tracking datasets containing asynchronous ADDED, MODIFIED, and DELETED state change events.

Logic Anomalies Solved & Human-Centric Remediation:

  • Orphan Modifications: Flagged MODIFIED records that had no prior baseline ADDED record. Built a reconciliation queue that routes orphan records to an audit table while auto-generating a synthetic baseline record using historical logs.
  • Ghost Updates: Intercepted records marked as MODIFIED despite identical timestamps and payload data. Implemented hashing comparison algorithms to drop zero-change payload writes, reducing storage bloat.
  • Zombie Shifts: Detected active operational records persisting after explicit DELETED events. Enforced strict tombstone record constraints that cascade-soft-delete downstream entries and issue alerts to operation managers.

Event-Driven Automated Ingestion Pipeline

Stack: Azure Data Factory (ADF), Databricks, PySpark, ADLS Gen2, SQL Server

Designed and deployed a dynamic, event-driven cloud ELT/ETL ingestion architecture triggered automatically upon file arrival inside Azure Data Lake Storage (ADLS Gen2).

Pipeline Mechanics: Azure Data Factory monitors blob container events and fires off Databricks notebooks running PySpark. The notebooks dynamically match file metadata against validation schemas, standardizing field names on the fly. Successfully transformed files are moved to /processed and historical raw files to /archive. Corrupted or schema-mismatched files are automatically isolated into a /quarantine zone. Dynamically created target staging tables in SQL Server to maintain fully auditable, queryable raw tables.

T-SQL Performance Tuning & Shift Deduplication

Stack: SQL Server, T-SQL, Partitioned Window Functions

Assisted in refactoring legacy stored procedures responsible for assigning sequence numbers to incoming labor shift logs, which was failing due to duplicate records and race conditions.

Optimization Strategy: Redesigned ordering and partition strategies using T-SQL window functions (ROW_NUMBER() OVER (PARTITION BY labor_id, shift_date ORDER BY updated_timestamp DESC)). Resolved multi-record ambiguities by implementing secondary tie-breakers based on shift status hierarchy. Improved query performance, eliminated duplicate shift assignments, and stabilized downstream analytics.
