CASE STUDY 01Panda Restaurant Group · Workforce data

Making labor-shift events trustworthy

Shift feeds carried ADDED, MODIFIED, and DELETED events. The challenge was distinguishing valid lifecycle changes from logically inconsistent records.

The challenge

A modified shift with no prior add, an update with no actual change, or a deleted shift that still appears active can make downstream workforce reporting unreliable.

What I did

Analyzed event sequences and developed business-rule validation logic to identify missing initial events, unchanged modifications, and inconsistent deletion states. Investigated anomalies using source data and SQL-based checks.

ENGINEERING IMPACT

Made shift-data exceptions easier to detect and investigate before they affected downstream consumers, supporting more reliable workforce datasets.

SQL · Data validation · Event lifecycle analysis
CASE STUDY 02Panda Restaurant Group · Ingestion

Automating ingestion from file arrival to SQL tables

A dynamic pipeline for processing incoming files without repeating the same manual work for every delivery.

The challenge

Incoming files required filename checks, consistent column structures, traceable archival, and a safe path for failed files.

What I built

Built an event-triggered Azure Data Factory workflow that starts when files arrive in ADLS Gen2. Databricks notebooks standardize column names; valid files proceed to processed storage and SQL Server tables, original files are archived, and failures are isolated in quarantine.

ENGINEERING IMPACT

Reduced manual handling and established a repeatable ingestion flow with clearer processing outcomes and easier failure investigation.

ADF · ADLS Gen2 · Databricks · PySpark · SQL Server
CASE STUDY 03Panda Restaurant Group · SQL reliability

Resolving ambiguous “latest shift” records

A stored procedure needed to identify the latest labor-shift entry, but duplicate and overlapping records made the ordering unreliable.

The challenge

Multiple records could compete for the same sequence position, making it difficult to determine which shift state should be treated as the latest.

What I did

Assisted in reviewing and optimizing the procedure's record-selection logic, including how row numbering, ordering, and duplicates were handled.

ENGINEERING IMPACT

Helped improve the clarity and consistency of latest-record selection in a critical workforce-data workflow.

SQL Server · T-SQL · Stored procedures · Deduplication

Finding anomalies earlier in the healthcare data flow

Snowflake · SQL · IC0 raw layer · Data QA
